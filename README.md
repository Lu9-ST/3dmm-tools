Assortment of tools for 3D Movie Maker modding. 

## 3DMM Exporter for Maverick Model 3D
Exports actors and props with animations from Maverick Model 3D (successor of Misfit Model 3D) to 3DMM.

**Linux only** for now. Help build the Windows DLL [here](/mm3d_plugin/README.md)!

(Coming soon: dedicated export dialog for easier options)

## 3DMM Scene Maker (For Blender)
Blender addon to bake scenes with camera angles and depth and turn them into 3DMM scenes.

## Pic2Scene
Converts pictures into single-camera 3DMM scenes with many options for handling depth and camera position.

## TTF-2-3DMM
Converts TTF/OTF fonts to 3DMM 3D Words.

## 3DMMEx Patches
Git patches to apply to the [3DMMEx repo](https://github.com/benstone/3DMMEx) **(specifically commit 9a44314)**. They are:
- Frame Interpolation + Vertex Blending (Multiplier, 1x = 6 FPS, 10x max)
- "Quick New" setting + v3DMM VXP Expansion loading (apply *after* applying previous patch)
  
Primarily for personal use. Might be very sloppy! Do not submit as PRs until it is more properly tested and verified. You have been warned.
